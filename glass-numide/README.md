# GLASS NUMIDE — Site Vitrine

## Déploiement GitHub + Vercel (5 minutes)

### 1. Aller sur GitHub
- Ouvrez https://github.com
- Cliquez "New repository"
- Nom : `glass-numide`
- Public ✅ → Create repository

### 2. Uploader le fichier
- Dans votre nouveau repo, cliquez "uploading an existing file"
- Glissez-déposez le fichier `index.html`
- Cliquez "Commit changes"

### 3. Déployer sur Vercel
- Ouvrez https://vercel.com
- "Add New Project" → Import depuis GitHub → `glass-numide`
- Cliquez Deploy → Votre site est en ligne !

---

## Accès Admin
- Cliquez le ⚙ en bas du site (footer)
- Mot de passe par défaut : **GlassNumide2024**

## Ce que vous pouvez modifier depuis l'Admin
- 📷 Galerie : ajouter/supprimer des photos par URL
- 📞 Contact : téléphones, email, Facebook, Maps, adresse
- 🕐 Horaires : ouvrir/fermer chaque jour, changer les heures
- 📝 À propos : texte de présentation
- 🔐 Sécurité : changer le mot de passe admin

## Ajouter des photos (Imgur - gratuit)
1. Allez sur https://imgur.com
2. Uploadez votre photo
3. Clic droit sur la photo → "Copier l'adresse de l'image"
4. Collez l'URL dans le panneau Admin → Galerie
